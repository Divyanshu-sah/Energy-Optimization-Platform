# EnergiX Copilot

Industrial energy intelligence dashboard built with React, Vite, Tailwind CSS, Framer Motion, and Recharts.

## Setup

```bash
npm install
npm run dev
```

## Available Pages

- Dashboard
- Machines
- Alerts
- Forecast
- Optimization
- Reports
- Simulator

## Notes

- Uses a mock scenario engine in `src/context/ScenarioContext.jsx`
- Tailwind is configured in `tailwind.config.js`
- UI components live under `src/components`
